# Домашнее задание к работе 7: Определение дня недели по номеру дня года

## Условие задачи

>Дано целое число **k** — номер дня в невисокосном году. Известно, каким днём недели приходится **1 января** (задаётся заранее). Определить, каким днём недели является **k-й день года**.


## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. **Ввод данных:**
   - `k` — номер дня года (1..365)
   - `d1` — день недели 1 января (1=Пн, ..., 7=Вс)
3. **Вычисления:**
   - `day = (d1 + k - 2) % 7 + 1`
4. **Ветвление (`switch`)**: в зависимости от значения `day` (1..7) вывести название дня недели, иначе - сообщение об ошибке.
4. **Вывод результата:** вывести значение `day`
5. **Конец**

## 2. Реализация программы

```c
#define _CRT_SECURE_NO_WARNINGS
#include <locale.h>
#include <stdio.h>

int main()
{
    setlocale(LC_ALL, "RUS");

    int k, d1, day;

    printf("Введите номер дня года k (1..365): ");
    scanf("%d", &k);

    printf("Введите день недели 1 января (1=Пн, ..., 7=Вс): ");
    scanf("%d", &d1);

    day = (d1 + k - 2) % 7 + 1; //расчёт дня недели k-го дня

    switch (day)
    {
    case 1:
        printf("День недели: Понедельник");
        break;
    case 2:
        printf("День недели: Вторник");
        break;
    case 3:
        printf("День недели: Среда");
        break;
    case 4:
        printf("День недели: Четверг");
        break;
    case 5:
        printf("День недели: Пятница");
        break;
    case 6:
        printf("День недели: Суббота");
        break;
    case 7:
        printf("День недели: Воскресенье");
        break;
    }

    return 0;
}
```
